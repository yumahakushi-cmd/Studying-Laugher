# ことばトレーニング（iPhone向けPWA）

英語・ドイツ語・イタリア語の単語を、単語帳ファイルごとに管理して学習するアプリです。

## できること
- 英語・ドイツ語・イタリア語の切り替え
- 単語帳JSONファイルの読み込み・ブラウザー内保存
- 保存済み単語帳から1冊または複数冊を選択して学習
- 単語・日本語訳・品詞・例文・例文訳の表示
- 4択クイズ、間違い単語の復習、単語検索
- 学習した単語数、正答率、最近の履歴
- localStorageへの学習履歴保存、IndexedDBへの単語帳保存
- Service Workerによるオフライン対応
- APIキーや外部AI APIは不要

## ファイル
- `index.html`：画面の骨組み
- `style.css`：見た目・スマートフォン向けレイアウト
- `app.js`：クイズ、統計、履歴、単語帳管理
- `words.js`：アプリ内蔵の初期単語
- `manifest.json`：ホーム画面追加用の設定
- `sw.js`：オフラインキャッシュ
- `word-import-template.json`：単語帳形式のサンプル
- `icons/`：PWAアイコン

## 単語帳を追加する
1. 「単語取込」を開く。
2. JSONファイルを1つまたは複数選ぶ。
3. 「単語帳を保存する」を押す。
4. 「単語帳」を開き、学習したい単語帳にチェックを入れる。
5. 「選択した単語帳で学習する」を押す。

一度読み込んだ単語帳はIndexedDBに保存され、同じブラウザー内では次回も使えます。アプリのコードを更新しても、通常は単語帳データは消えません。

### 新しい単語帳JSON形式（推奨）
1ファイルにつき1冊の単語帳を作ります。

```json
{
  "formatVersion": 1,
  "name": "英検2級",
  "language": "en",
  "description": "英検2級の試験対策語彙",
  "words": [
    {
      "word": "sustainable",
      "meaning": "持続可能な",
      "pos": "形容詞",
      "example": "We need sustainable energy sources.",
      "exampleJa": "私たちには持続可能なエネルギー源が必要だ。"
    }
  ]
}
```

`language` は `en`（英語）、`de`（ドイツ語）、`it`（イタリア語）のいずれかです。各単語には `word`、`meaning`、`pos`、`example`、`exampleJa` が必要です。

### 以前のJSON形式も読み込めます
以前の形式は、`version: 1` と `words` オブジェクトの中に `en`、`de`、`it` の配列を持ちます。旧形式を読み込むと、単語が入っている言語ごとに単語帳を分けて保存します。

同じ内容の単語帳を再度読み込んだ場合は重複をスキップします。内容が異なる単語帳は別々に保持されます。

## 保存データと注意点
- 学習履歴・統計・間違い記録は、従来どおり `localStorage` の `kotobaTrainerData_v1` に保存します。
- 単語帳は `IndexedDB` の `kotobaTrainerBooksDB` に保存します。
- 単語帳の削除は、その単語帳だけに作用し、学習履歴は削除しません。
- 「履歴を消去」は履歴・統計・間違い記録を消去しますが、単語帳データは消去しません。
- データはそのブラウザー・端末に保存され、別端末とは自動同期されません。
- Safariなどでサイトデータを削除すると、学習履歴や単語帳が失われる場合があります。元のJSONファイルもバックアップとして保管してください。
- プライベートブラウズやブラウザーの容量制限などにより、保存が制限されることがあります。

## ローカルで動作確認
PWA機能（Service Worker）は `file://` で開くと動きません。

1. このフォルダーをパソコンに展開する。
2. ターミナル／コマンドプロンプトでフォルダーに移動する。
3. `python -m http.server 8000` を実行する。
4. ブラウザーで `http://localhost:8000` を開く。

VS Codeを使う場合はLive Serverなどでも確認できます。

## GitHub Pagesで公開・更新する
1. リポジトリ内のファイルを更新する。
2. `index.html`、`style.css`、`app.js`、`sw.js`、`word-import-template.json` など変更したファイルをアップロードする。
3. `sw.js` の `CACHE_NAME` を変更済みであることを確認する（現在は `kotoba-trainer-v4`）。
4. iPhoneのSafariで公開URLをオンラインで開き、新しいキャッシュが読み込まれるまで待つ。
5. 単語帳画面で保存済み単語帳が残っていること、クイズ・履歴・復習が動作することを確認する。

キャッシュ更新はアプリのファイルを更新するためのもので、IndexedDBやlocalStorageを削除する処理を追加してはいけません。

## iPhoneのホーム画面に追加
1. iPhoneのSafariで公開URLを開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. 名前を確認して追加する。
