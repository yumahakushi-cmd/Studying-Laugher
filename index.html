おすすめの新しい単語帳形式 
{
  "formatVersion": 1,
  "name": "英検2級",
  "language": "en",
  "description": "英検2級の試験対策語彙",
  "words": [
    { "word": "sustainable", "meaning": "持続可能な", "pos": "形容詞", "example": "We need sustainable energy sources.", "exampleJa": "私たちには持続可能なエネルギー源が必要だ。" }
  ]
}

1ファイルにつき1冊の単語帳を作ります。language は en（英語）、de（ドイツ語）、it（イタリア語）です。以前の version / words 形式も読み込めます。その形式は、単語がある言語ごとに単語帳へ分けて保存されます。

同じ内容の単語帳を再度読み込むと重複保存をスキップします。別の単語帳の削除や既存の学習履歴の消去は行いません。
