サンプルJSONをダウンロード

取り込み前です。サンプル形式に合わせたJSONを選んでください。

JSONの形式を確認する 
{
  "version": 1,
  "words": {
    "en": [{ "word": "example", "meaning": "例", "pos": "名詞", "example": "This is an example.", "exampleJa": "これは例です。" }],
    "de": [],
    "it": []
  }
}

各単語に word（単語）、meaning（日本語訳）、pos（品詞）、example（例文）、exampleJa（例文の日本語訳）が必要です。

安全のため、取り込みは追加のみです。既存の単語・学習履歴・復習記録は削除も上書きもしません。同じ言語に同じ単語がある場合はスキップします。
